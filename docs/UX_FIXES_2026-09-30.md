## Provedené kontroly

Browser kontroly používají Chromium, browser harness a simulovaný extension host.
Nejsou důkazem nativního editorového prostředí ani živých odpovědí modelu.

- `npm install --save-dev @playwright/test`: dokončeno.
- `npm run test:browser`: 15/15 prošlo. Zahrnuje všech 12 uspořádaných dvojic tří
  ukázek a jedné revize, měsíční/roční billing, zachování iframe a kontrast.
- Ověřené šířky pracovního panelu: 1440, 720, 600 a 360 px. Choose/Refine i exportní
  tlačítka jsou při kontrolovaném scénáři v dostupné části obrazovky. Dlouhá hypotéza
  nepřesouvá jeden náhled pod ostatní.
- Orientační profil 15 směrů + Original: 190 ms na zadání 48 znaků přes Playwright;
  plná zpráva 2 364 148 znaků oproti 158 znakům status delta. Všech 16 iframe zůstalo
  připojených. Nejde o přenositelný benchmark; měření nedokládá potřebu dalšího
  rozsáhlého přepisování React contextu.

`npm run check` prošel: lint, formátování, **49/49 unit testů**, TypeScript, Vite
a esbuild. Browser testy běží samostatně; nejsou skrytou součástí tohoto příkazu.

## Co ještě vyžaduje skutečný editor a účet

Izolovaný Cursor Extension Development Host byl dvakrát spuštěn s dočasným
workspace a testovací komponentou. Log zaznamenal aktivaci rozšíření a dokončení
příkazu Explore Component, ale testovací okno se zavřelo dříve, než kontrola
ověřila zobrazený snapshot a navazující interakce. Tento pokus **není úspěšný
nativní smoke test**. Instalace výsledného VSIX, SecretStorage, nativní clipboard,
Save HTML a všechna skutečná editorová témata zůstávají neověřené.

Cursor CLI nebyl nalezen v očekávaných `~/.local/bin/agent` ani `cursor-agent`.
Aktuální PRODUCT/LLM_CONTRACT popisují jeho samostatný profil, historii, omezení
a zrušení; adaptérové testy ověřují řízení procesu a konfiguraci. Živé přihlášení,
skutečné vynucování oprávnění instalovaným CLI, účetní limity a historii nelze
potvrdit z mocků. Žádné živé OpenAI/Anthropic/Cursor generování se při této UX
implementaci neprovedlo. Kvalita reálných modelových návrhů tedy není ověřená.

Nejmenší navazující průchod: v Cursoru F5 → testovací komponenta s neuloženou
změnou → kontrola snapshotu → nakonfigurovaný provider a potvrzený živý request
→ refine → Choose se zachovaným stavem → Copy for Cursor → Save HTML. CLI pak
vyžaduje vlastní kontrolu zákazů nástrojů, zrušení procesů a přetrvání historie
podle [checklistu](DEMO_CHECKLIST.md#connect-and-use-cursor-cli).
