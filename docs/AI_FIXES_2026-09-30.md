# AI a Generate — opravy 0.2.3

## Příčiny a opravy

- Kontrola Cursor loginu měla jen boolean a automatické chyby se skrývaly. Panel nyní
  rozlišuje kontrolu, přihlášení, odhlášení a chybu; zobrazuje bezpečný důvod nedostupnosti.
  Check Cursor a Sign in to Cursor CLI jsou dostupné přímo u zadání. Oba příkazy mají
  pevně povolené akce v protokolu, vyžadují trust a neposílají zdroj modelu.
- Návrat z prohlížeče mohl nastat před dokončením CLI loginu. Po spuštění loginu se stav
  ověřuje každé tři sekundy nejvýše tři minuty, také při zavření jeho terminálu. Úspěch,
  reset nebo zavření panelu kontrolu ukončí; odhlášení automatickou kontrolu pozastaví.
  Kontrola vyvolaná během jiné operace se odloží, neztratí.
- Pomalejší stará aktualizace providerů mohla přepsat novější přihlášení na false.
  Publikuje se pouze aktuální výsledek a Cursor stav se čte po asynchronním čtení klíčů.
- Chyba SecretStorage u OpenAI/Claude mohla zablokovat celý getState včetně Cursoru.
  Nyní se týká pouze příslušného providera a má vlastní vysvětlení.
- Nastavení API klíče nechávalo vybraný jiný neaktivní provider. Úspěšná konfigurace
  dostupného providera jej vybere bez ztráty zadání nebo náhledů.
- Validátor Cursor modelů odmítal současnou CLI syntaxi s parametry v hranatých závorkách.
  Povoluje omezenou syntaxi key=value a stále předává model jako jediný argument,
  bez shellu a bez možnosti přidat jiné CLI přepínače.
